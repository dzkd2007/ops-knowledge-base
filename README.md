# Ops Knowledge Base

Team operational knowledge base for incident patterns, runbooks, and best practices.

## Structure

```
runbooks/          # Incident response runbooks
  ├── *.md         # Individual runbook entries
incidents/         # Post-incident reports
  ├── *.md         # Individual incident reports
```

## Contributing

Knowledge entries are auto-generated by Quick Desktop after incident resolution and submitted via PR for team review.
